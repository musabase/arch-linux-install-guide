# HyDE Hyprland on Arch Linux

HyDE is a visually polished Hyprland configuration designed
to provide a modern and cohesive desktop experience.

Unlike minimal tiling setups that focus only on functionality,
HyDE combines performance, aesthetics, and usability to create
a complete Hyprland environment on Arch Linux.

The project includes carefully designed themes, system scripts,
and UI components that work together to deliver a clean and
consistent Wayland desktop.

---

# Why Use HyDE

HyDE is useful for users who want:

- A visually refined Hyprland environment
- Preconfigured themes and UI components
- Smooth animations and polished desktop design
- A ready-to-use setup without heavy manual configuration
