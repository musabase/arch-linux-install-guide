# Hyprland Setups on Arch Linux

Hyprland is a dynamic tiling Wayland compositor that provides modern
animations, flexible layouts, and a keyboard-driven workflow.

Unlike traditional desktop environments such as KDE or GNOME,
Hyprland focuses on efficient window management while still
delivering a visually polished experience.

This directory lists several popular Hyprland configurations
documented on MusaBase.
